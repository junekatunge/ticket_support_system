1. SIGN UP FOR FREE HOSTING
   → Go to: https://infinityfree.net
   → Create account (FREE)
   → Choose subdomain name

2. CREATE DATABASE
   → Open cPanel
   → MySQL Databases
   → Create database & user
   → ⚠️ WRITE DOWN CREDENTIALS!

3. UPLOAD FILES
   → cPanel → File Manager
   → Go to htdocs folder
   → Upload helpdesk-deployment.zip
   → Extract zip
   → Move all files from helpdesk-core-php to htdocs

4. IMPORT DATABASE
   → cPanel → phpMyAdmin
   → Select your database
   → Import → Choose file
   → Upload: database/helpdesk_core_php.sql

5. UPDATE CONFIG
   → Edit: src/Database.php
   → Add your database credentials:
     - Host: localhost
     - Username: (from step 2)
     - Password: (from step 2)
     - Database: (from step 2)

6. TEST WEBSITE
   → Visit: https://yoursite.infinityfreeapp.com
   → Login with: johndoe@helpdesk.com

7. INSTALL ON iPHONE
   → Open Safari on iPhone
   → Go to your website
   → Tap Share button
   → Add to Home Screen
   → Done! ✅
